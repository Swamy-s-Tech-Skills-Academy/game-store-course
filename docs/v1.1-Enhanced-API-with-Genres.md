# GameStore API v1.1: Enhanced In-Memory API with Genres

## Overview

This document outlines the implementation plan for v1.1 of the GameStore API, which adds Genre management and enhances the existing Game functionality.

## New Features

### Genre Management

- Complete CRUD operations for Genres
- Relation between Games and Genres
- Genre-based filtering for Games

### Enhanced Error Handling

- Structured error responses
- Global exception handling
- Validation improvements

### Query Parameters

- Filtering games by genre
- Basic pagination support
- Sorting capabilities

### 3. Add Genre Endpoints

```csharp
// Data store
List<Genre> genres = [
    new Genre { Id = Guid.Parse("c8d4c053-3bc9-4b31-8c13-bd0c4dac7797"), Name = "Fighting" },
    new Genre { Id = Guid.Parse("5b37d731-863c-4bd1-90c7-b9a5938dea6c"), Name = "Roleplaying" },
    new Genre { Id = Guid.Parse("a12b2dfe-5a9f-4e8c-82c4-8a2924e142bb"), Name = "Sports" },
    new Genre { Id = Guid.Parse("78843852-f841-4099-93fb-ebee2d236d9a"), Name = "Action" },
    new Genre { Id = Guid.Parse("b73a664b-648d-4022-8343-22748d856b1e"), Name = "Adventure" }
];

// GET /genres
app.MapGet("/genres", () => genres)
    .WithName("GetAllGenres")
    .WithTags("Genres");

// GET /genres/{id}
app.MapGet("/genres/{id:guid}", (Guid id) =>
{
    Genre? genre = genres.FirstOrDefault(g => g.Id == id);
    return (genre is null) ? Results.NotFound() : Results.Ok(genre);
})
    .WithName("GetGenreById")
    .WithTags("Genres");

// POST /genres
app.MapPost("/genres", (Genre genre) =>
{
    genre.Id = Guid.NewGuid();
    genres.Add(genre);
    return Results.CreatedAtRoute("GetGenreById", new { id = genre.Id }, genre);
})
    .WithName("CreateGenre")
    .WithTags("Genres")
    .WithParameterValidation();

// PUT /genres/{id}
app.MapPut("/genres/{id:guid}", (Guid id, Genre updatedGenre) =>
{
    Genre? existingGenre = genres.FirstOrDefault(g => g.Id == id);
    if (existingGenre is null) return Results.NotFound();

    existingGenre.Name = updatedGenre.Name;

    return Results.NoContent();
})
    .WithName("UpdateGenre")
    .WithTags("Genres")
    .WithParameterValidation();

// DELETE /genres/{id}
app.MapDelete("/genres/{id:guid}", (Guid id) =>
{
    Genre? existingGenre = genres.FirstOrDefault(g => g.Id == id);
    if (existingGenre is null) return Results.NotFound();

    // Check if any games use this genre
    if (games.Any(g => g.GenreId == id))
    {
        return Results.BadRequest("Cannot delete genre that is used by games");
    }

    genres.Remove(existingGenre);
    return Results.NoContent();
})
    .WithName("DeleteGenre")
    .WithTags("Genres");
```

### 4. Update Game Endpoints

```csharp
// Update GET /games to include Genre information
app.MapGet("/games", (string? genreName) =>
{
    IEnumerable<Game> result = games;

    if (!string.IsNullOrWhiteSpace(genreName))
    {
        // Filter by genre name
        Guid? genreId = genres
            .Where(g => g.Name.Equals(genreName, StringComparison.OrdinalIgnoreCase))
            .Select(g => g.Id)
            .FirstOrDefault();

        if (genreId != Guid.Empty)
        {
            result = result.Where(g => g.GenreId == genreId);
        }
    }

    // Enrich games with genre data
    return result.Select(game =>
    {
        game.Genre = genres.FirstOrDefault(g => g.Id == game.GenreId);
        return game;
    });
})
    .WithName("GetAllGames")
    .WithTags("Games");
```

### 5. Add Basic Exception Handling

```csharp
// Add to the pipeline before endpoints
app.Use(async (context, next) =>
{
    try
    {
        await next(context);
    }
    catch (Exception ex)
    {
        context.Response.StatusCode = StatusCodes.Status500InternalServerError;
        await context.Response.WriteAsJsonAsync(new
        {
            error = "An unexpected error occurred",
            message = ex.Message,
            requestId = Guid.NewGuid()
        });
    }
});
```
